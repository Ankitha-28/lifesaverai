# 🚨 Life Saver AI

Life Saver AI is a Python-based desktop emergency assistance application developed to enhance personal safety for women, elderly individuals, children, solo travelers, and people in vulnerable situations.

The application provides a simple and user-friendly interface that allows users to quickly send emergency alerts via email. Users can enter emergency contact details, write an emergency message, and instantly notify a recipient with a single click.

## Features

* 📧 Emergency email alert system
* 📱 Support for multiple emergency contact numbers
* 📝 Custom emergency message input
* 🚨 One-click alert sending
* 🎨 Modern and user-friendly graphical interface using Tkinter
* 🔒 Secure email delivery using Gmail SMTP and App Password authentication
* 💻 Lightweight desktop application built entirely with Python

## Technologies Used

* Python
* Tkinter (GUI)
* SMTP (Email Service)
* EmailMessage Library

## How It Works

1. Enter the recipient's email address.
2. Add emergency contact numbers.
3. Type an emergency message.
4. Click **SEND ALERT**.
5. The application sends an emergency email instantly to the specified recipient.
